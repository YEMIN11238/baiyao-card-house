# 百妖牌馆 · 流程试玩版

本地单人比鸡游戏。以所提供视频的可见流程为参考，先跑通玩法，再替换美术。当前不是视频原游戏的源码或完整数值还原版；对照见 `REFERENCE.md`。

## 运行

需要 Node.js 20 或更新版本。没有第三方依赖，不需要 npm install。

```sh
npm start
```

打开 http://127.0.0.1:5173 。macOS 也可双击 `启动牌馆.command`。服务器仅监听本机，终端按 Ctrl+C 关闭。直接双击 index.html 会受到浏览器模块限制，请使用启动方式。

## 已完成流程

主菜单（新开、继续、设置、成就）→入场→发九张牌→分小中大三墩→逐墩翻牌和魂值结算→商店／祭坛→下一局。每章三局，共十二章；魂值耗尽进入失败，完成36局进入通关。重新开局会确认覆盖，成就单独保留。

牌桌支持选三张放入一墩、拖动单张、单张交换、收回重排、付费自动理牌、大小王选面、符令消耗、奇珍被动、规则查看和结算明细。商店有六个货位、刷新、容量和余额校验；祭坛可更换目标、附灵、刻印、祭拜。音效、合成背景音乐、音量、翻牌速度均可调整。

进度自动写入当前浏览器的 localStorage：手牌、对手布局、随机状态、改造、背包和商店都保留；刷新不会重新发牌或重复给奖励。不同浏览器的进度不共享。

## 操作

- 点击底部手牌选中，最多三张，再点小、中、大墩的菱形按钮放入。
- 单张可以拖到牌位；先选一张再点击已摆好的另一张，可以交换。
- “收回重排”不收费；右键已摆好的牌可以单张收回。
- 九张摆好且小墩≤中墩≤大墩时，右下角可“结束出牌”。
- 大小王须先点击并选定牌面；按花色可筛选。
- 符令在左下角背包中使用；商店点击货品购买，悬停可看完整效果。
- Esc 关闭弹窗或打开设置；弹窗支持键盘焦点循环。

## 美术替换

当前场景、猫掌柜、牌面和货品使用 CSS/SVG 占位，无外部图片和字体请求。图片生成后放入 `assets/`，在 `assets.js` 填入路径即可。

| 配置 | 用途 |
| --- | --- |
| room | 1440×810 暖灯牌馆与空青绿牌桌背景 |
| host | 透明背景猫掌柜立绘，中心上方 |
| cardBack | 竖版牌背 |
| cardFaces | 按实体牌ID或点数替换中央插画 |
| items | 按货品ID替换商店和背包插画 |

点数、花色、改造标记保留为界面元素，以免插画影响读牌。当前按横屏1440×810整体缩放，适合桌面或横屏平板；未做手机竖屏专用布局。

## 源码与检查

`engine.js` 负责牌型、随机、规则、物品、经济、流程与存档校验，所有操作返回新状态。`app.js` 负责交互、翻牌演出、持久化和音频；`styles.css` 与 `scenery.js` 负责占位美术；`server.mjs` 提供本地静态服务。

```sh
npm test
```

单元测试覆盖牌型、A23顺子、倒墩、实体守恒、王变化、摆牌换位、消耗、商店、祭坛、存档恢复、完整36局和失败分支。浏览器已实际验证主菜单、分牌、结算、购买、附灵刻印祭拜、符令和大小王变化、刷新读档。流程通过不代表数值平衡、市场或Steam发布条件已验证。

这是浏览器本地可玩版本，尚未打包 Steam 桌面客户端，也未接入 Steam SDK。可先通过本机试玩验证流程，再决定桌面封装与正式图片、音乐、配音资源。
