# 美术与素材

绛紫牌桌、骨白纸牌、朱砂细节与旧金边饰，构成百妖牌馆当前的画面基调。角色采用圆脸、短身、简化服饰的半身造型，保持牌局中清楚可读的轮廓。

## 角色与题材

九尾狐、鹿蜀、旋龟取材于《南山经》，天狗、狰取材于《西山经》，应龙见《大荒东经》。本项目使用古籍中的名称与基本原型，圆润比例、服装、配色和牌馆身份属于游戏美术演绎。

- [《南山经》](https://zh.wikisource.org/zh-hans/山海經/南山經)
- [《西山经》](https://zh.wikisource.org/zh-hans/山海經/西山經)
- [《大荒东经》](https://zh.wikisource.org/zh-hans/山海經/大荒東經)

## 生成与界面分层

当前 PNG 美术由内置 imagegen 生成并按现有画风迭代。README 中的五张展示图是游戏实机截图。仓库不包含参考视频文件，也未把参考视频截图作为游戏素材。

点数、花色、牌型提示、价格、说明和按钮保留为 HTML/CSS，避免把规则文字烘焙在图片中。表情通过切换立绘实现；效果源文件是静态透明 PNG，由界面控制短暂动画，不是逐帧角色动画。
