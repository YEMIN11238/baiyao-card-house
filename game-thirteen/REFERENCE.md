# 十三张规则与视频参考

## 基础牌规

2026-10-22核对 [Pagat：Chinese Poker / Pusoy / Russian Poker](https://www.pagat.com/partition/pusoy.html)。该规则说明使用52张普通牌，每人13张，按前三、中五、后五分组，并按普通五张扑克牌型比较；三张前墩只有三条、对子、散牌，不承认三张顺子或同花。

本版采用上述基础分组、牌型顺序、同型点数比较和无花色决胜规则。A2345按5高顺子处理，QKA23不算顺子。

十三张存在多种计分及特殊牌约定。本原型明确选择：

- 允许相邻墩同强；跨3张与5张同型比较时，比较共同存在的关键点数，忽略五张多出来的余牌项。
- 每墩胜+3魂值、负−3魂值、和0。没有打枪加成、特殊十三张牌型直接获胜、四条／葫芦／同花顺额外奖励。
- 只与一个电脑对手对局。双方同时持有各自13张牌，对手先锁定布局，不读取玩家手牌；其组合选择随章节变化。
- 不使用大小王。改点数、改花色的符令属于闯关扩展，不能在同一手里生成重复牌面。改造只影响本局牌面，祭坛属性可保留到以后发牌。

以上选择会在游戏内规则中明确显示，不混称为所有地方通用的十三张规则。

## 视频借鉴范围

用户视频中的《牌灵·百妖会》展示九张比鸡，原可玩版本保留于 `../game/`。用户后来指定改做十三张并保留旧版，因此本目录是独立衍生原型，不再把十三张称为视频原玩法。

沿用的视频可见方向：东方妖怪牌馆、暖灯和青绿桌面；主菜单、入场、分墩、逐墩揭牌、结算、六格商店和祭坛、下一局、失败与通关；初始100魂值；十二章三十六局；自动理牌−1；附灵×2、刻印×1.5等界面展示方向。当前版本使用自行生成并迭代的山海经题材美术，不使用视频截图作为素材；角色、配色和十三张玩法均有区别。音乐使用程序合成，演出按本项目交互实现。

为十三张新加入：3／5／5容量与倒墩提示、五张完整牌型、十三张手牌排序、三步图示教学、三种摆牌参考、独立的端口与存档。功能牌文案和判定同步适配，例如全手换牌改为13张、“七黑两红”改为“七黑六红”，五张的两对和葫芦按新牌型参与效果判定。

当前商店、功能牌价格、AI估值及36局难度仍为可试玩数值，需要分别试玩比鸡与十三张后再决定。主流程可运行不等于平衡或市场已验证。
