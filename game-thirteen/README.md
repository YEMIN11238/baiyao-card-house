# 百妖牌馆 · 十三张独立版

基于十三张／十三水的本地单人闯关原型。前墩3张、中墩5张、后墩5张，搭配符令、奇珍、商店和祭坛。原比鸡版完整保留在同级的 `game/`，两版可以同时运行。

## 启动与返回旧版

需要 Node.js 20 或更新版本。没有第三方依赖，无需 npm install。

在本目录执行 `npm start`，打开 http://127.0.0.1:5174/ 。macOS 可双击本目录的 `启动十三张.command`。

双击启动脚本后，游戏服务在后台运行，可以关闭弹出的终端窗口；再次双击会复用已运行的服务。电脑重启后需要重新双击启动。启动日志和进程号保存在 `.runtime/`。通过 `npm start` 启动时仍需保留该终端。

原比鸡版：在 `../game/` 执行 `npm start`，打开 http://127.0.0.1:5173/ ，或双击该目录的 `启动牌馆.command`。十三张主菜单也有打开比鸡版的链接。两个服务分别在自己的终端按 Ctrl+C 关闭。

两个版本的源码、端口和存档键独立。十三张不会读取、迁移或覆盖比鸡进度；比鸡版源码保留于同级 `game/`，可直接运行。浏览器存档只在原浏览器、原地址可用，复制源码不会带走浏览器存档。再次运行时请继续使用 127.0.0.1 和对应端口。

## 基础规则

- 一副52张普通牌，不含大小王。双方各发13张。
- 每张手牌恰好用一次，前墩3张、中墩5张、后墩5张。必须满足前墩≤中墩≤后墩，否则提示倒墩并禁止开牌。
- 前墩只认散牌、对子、三条，三张同花或连号不构成同花、顺子。
- 五张牌由弱到强为散牌、对子、两对、三条、顺子、同花、葫芦、四条、同花顺。
- 同型按关键点数、余牌比较；花色没有高低，同点数平局。A2345为最小顺子，10JQKA最大。
- 比较前墩与中墩的合法性时只比两者共同的关键点数；完全相同允许摆放。详细约定见游戏内规则。

每墩基础输赢为±3魂值，平局0；暂不加入地方打枪、特殊十三张自动获胜或奖励番数。这是本原型的闯关计分选择，不是声称所有地区都采用这个计分。基础牌规与视频参考的区分见 `REFERENCE.md`。

## 试玩流程与操作

主菜单 → 入场／三步图示教学 → 发13张牌 → 摆牌 → 逐墩揭牌与结算 → 六格商店／祭坛 → 下一局。初始100魂值，每章三局，共十二章；魂值耗尽失败，存活完成36局通关。

- 点击底部手牌多选，最多五张，再点前／中／后墩按钮放入。前墩最多三张。
- 分批放牌会保留墩内已有牌；容量不足时会提示，不会替你清空原牌。
- 可拖动单张到牌位；先选一张，再点已摆好的另一张可交换。右键已摆好的牌可收回。
- 按点数／花色排序、手动调整与收回重排均免费。
- “摆牌参考”免费展示均衡三墩、优先前墩、做强后墩三种方案；采用或“自动理牌”花1魂值。
- 建议与对手AI各自只使用自己的手牌。建议按牌型估值，未计算全部奇珍收益，不保证赢牌。
- 思考不限时。三墩合法后才能“结束出牌”；可看逐墩动画、跳过动画和查看明细。
- 符令在背包中使用，奇珍持续生效。改牌后仍要检查倒墩；不能把同手牌改出重复牌面。
- 每局结束可买货、刷新、选择牌库目标附灵或刻印、祭拜；消费后至少保留1魂值。
- Esc关闭弹窗或打开设置。音效、合成背景音乐、音量和翻牌速度可调。

存档自动保存手牌、摆放、对手布局、随机状态、功能牌、改造与商店。刷新不会重发牌或重复领取奖励。十三张使用 `yaopai-thirteen-*-v2` 存档键，包含规则版本校验。

## 美术与源码

已接入山海经妖怪牌馆美术：绛紫牌桌、骨白纸牌、朱砂与旧金，共64张选用PNG，保存在 `assets/shanhai-v2/`。美术与素材清单见 [素材说明](../docs/ART.md)。原始生成记录与本地工作文件不纳入公开仓库。点数、花色、价格、文字和改造标记仍由界面独立绘制。界面按1440×810横屏等比缩放，尚未制作手机竖屏布局。

九尾狐、鹿蜀、旋龟、天狗、狰、应龙各负责两章。每位对手有平静、得意、落败状态；九尾狐另有思考、吃惊。玩家获胜时对手显示落败，玩家失分时对手显示得意。胜负平结算装饰、通关/失败背景、商店/祭坛面板与四类短暂效果已接入。图片三路加载并验证解码，同一图片的所有位置共享已加载内容；失败时可点击重新加载。

本地历史备份继续保留，但不纳入公开仓库。后续源码版本通过 Git 提交记录追踪。

`engine.js`负责牌型、组合求解、游戏状态、功能牌、经济与存档；`app.js`负责教学、交互、动画与持久化；`styles.css`和`scenery.js`负责画面；`server.mjs`仅提供本机静态服务。

执行 `npm test` 验证规则和流程。测试覆盖五张九级牌型、前墩限制、A2345、无花色决胜、跨3／5比较、倒墩、三种建议、52张实体牌守恒、功能牌、商店祭坛、旧档拒绝、100魂值起步的完整36局和失败分支。

本版用于对比两种玩法与验证操作流程。已完成这一批生成美术的接入；仍需后续做美术迭代、数值平衡、角色逐帧动画、正式音乐，以及Steam客户端打包与SDK接入。
